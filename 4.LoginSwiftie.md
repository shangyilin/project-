# Taylor Swift Login (Python GUI Project)

## 1. Programming Language Used
- Python 3
- Tkinter (Python standard library for GUI)

## 2. Purpose of the Code
This project implements a simple graphical login interface using Tkinter. The user enters a username and password, and the program checks whether they match predefined credentials. This is a Swiftie check to see whether you are a fan of Taylor Swift.
There are two hints:
  - Username is TS full name
  - Password is TS birthday in YYYYMMDD (year + month + day)

If the login is successful, the interface changes to display a welcome message. If the login fails, an error message is shown and the number of attempts is increased. A reset button allows the user to clear the input fields and try again.

## 3. Scale of the Project
- Single main window created using Tkinter
- Multiple GUI components:
  - Labels
  - Entry fields
  - Buttons
  - Message boxes
- Event-driven button functions (`b1fun`, `b2fun`)
- Tracks login attempts using a counter variable

## 4. Use of Object-Oriented Concepts
This project uses Tkinter's object-based structure. Each GUI element (such as `Label`, `Entry`, and `Button`) is created as an object.

Although the program is not fully class-based, it still demonstrates structured organization by separating functionality into different functions (login logic, reset logic, and interface update logic). This makes the program easier to read and modify.

## 5. Use of Data Structures
The program uses:
- String variables to store the correct username and password
- Integer variables to track the number of login attempts
- Tkinter `StringVar` to dynamically update the attempt counter label

These variables represent the program state and are updated based on user interaction.

## 6. Interesting Use of Data Structures / Algorithms
The main logic is a simple conditional check that compares user input with predefined credentials.

The program also updates the interface dynamically after successful login by destroying the original widgets and displaying new content. This demonstrates basic state transition in a GUI application.

The attempt counter updates in real time, showing how variable changes can be reflected in the interface using Tkinter’s variable binding system.
