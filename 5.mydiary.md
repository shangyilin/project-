# Diary Notebook (Python Tkinter)

## 1. Programming Language Used
- Python 3
- Tkinter (Python standard library for GUI)
- `os` module for file name handling

## 2. Purpose of the Code (Main Functionality)
This project is a simple diary/notebook application with a graphical interface. It provides a multi-line text box for writing notes, supports scrolling, and allows the user to open and save `.txt` files through a menu bar.

It also includes small formatting helpers (inserting a dashed line or a row of heart symbols) to make diary entries easier to organize.

## 3. Scale of the Project
- Single-window Tkinter GUI
- Main components:
  - `Text` widget for writing/editing content
  - `Scrollbar` for navigation
  - Buttons for quick insertion actions
  - Menu bar with file operations (Open / Save / Save As)
  - Message boxes for save notifications
- Uses multiple functions to separate responsibilities (open, save, save as, insert helpers)

## 4. Use of Object-Oriented Concepts
This project uses Tkinter’s object-based widgets (e.g., `Text`, `Scrollbar`, `Button`, `Menu`) and connects them through functions and event callbacks.

## 5. Use of Data Structures
The program mainly works with strings:
- The diary content is handled as text retrieved from the `Text` widget.
- File paths and file names are stored as strings (using a `filename` variable).
- `os.path.basename()` is used to display the file name in the window title.

## 6. Interesting Use of Data Structures / Algorithms
The main logic is based on event-driven GUI programming:
- Menu actions trigger functions to open or save files.
- The program reads the file content into the text box and writes the current text box content back to a file.
- If the file has not been saved before, the program automatically switches to “Save As” logic.
