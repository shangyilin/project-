# Restaurant Management System (Python)

## 1. Programming Language(s) Used
- Python 3 (standard library only)

## 2. Purpose of the Code (Main Functionality)
This project implements a simple restaurant management system using a class-based structure.

The program allows the restaurant to:
- Add items and prices to a menu
- Book tables
- Record customer orders
- Display menu items, table reservations, and customer orders

## 3. Scale of the Project
- 1 main class: `Restaurant`
- Multiple methods to handle different responsibilities:
  - `add_item_to_menu`
  - `book_tables`
  - `customer_order`
  - `print_menu_items`
  - `print_table_reservations`
  - `print_customer_orders`
- A `main()` function to demonstrate how the system works

## 4. Use of Object-Oriented Concepts
This project uses a class-based design.
The `Restaurant` class groups together:
- Menu data
- Table reservations
- Customer orders

Each responsibility is handled by a separate method. This keeps the program structured and easier to expand compared to a purely procedural approach.

The class stores internal state (menu items, reservations, and orders) and updates that state through method calls.

## 5. Use of Data Structures
The program uses several basic data structures:

- A dictionary (`menu_items`) to store menu names and prices.
- A list (`book_table`) to store reserved table numbers.
- A list of dictionaries (`customer_orders`) to store order details, including table number and item name.

These structures allow the program to manage related information in a clear and organized way.

## 6. Interesting Use of Data Structures / Algorithms
The key idea in this project is using a dictionary to represent the menu, which allows fast lookup of prices by item name.

Orders are stored as dictionaries inside a list, which makes it possible to record structured information for each table.
