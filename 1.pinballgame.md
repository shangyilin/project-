# Tkinter Pinball Game

## 1. Programming Language Used
- Python 3
- Tkinter (Python standard library for GUI)


## 2. Purpose of the Code

This project implements a simple graphical pinball game using Python and Tkinter.

The main functionality includes:

- Rendering a ball and paddle using a graphical canvas
- Real-time animation through a continuous game loop
- Keyboard-controlled paddle movement
- Collision detection between:
  - Ball and walls
  - Ball and paddle
- Game over detection when the ball reaches the bottom
- Restart functionality via mouse click

The purpose of this project was to practice the folowing skills:
- Event-driven programming
- GUI development
- Object-oriented design

## 3. Scale of the Project

- Number of classes: 2 main classes (`Ball`,`Paddle`)
- Number of methods: 12 methods
- Lines of code: 170 lines
- Includes:
  - - Keyboard input control
  - Mouse click restart
  - Continuous game loop
  - Collision detection


## 4. Use of Object-Oriented Concepts

This project is written using a class-based structure rather than placing all the code in a single block.

The game is divided into two main classes: `Ball` and `Paddle`. Each class manages its own data and behavior. For example, the `Ball` class controls its position, movement, and collision detection, while the `Paddle` class handles user input and boundary checking.

Key actions such as updating positions, detecting collisions, and resetting the game state are implemented as methods within the classes.

The `Ball` object also interacts with the `Paddle` object to check for collisions. This structure keeps the program organized and makes the logic easier to understand and maintain.


---

## 5. Use of Data Structures

- Lists are used to randomize the initial speed of the ball at the start of the game.

- The coordinate values returned by Tkinter (via `canvas.coords()`) are used to determine the position of the ball and paddle. These values are compared to check whether objects collide or reach the boundary.

- Boolean variables are used to control the game state, such as detecting when the ball hits the bottom and deciding when the game should restart.

## 6. Interesting Use of Data Structures / Algorithms

- The main algorithm in this project is the collision detection logic.

- The program continuously checks the coordinates of the ball and compares them with the positions of the paddle and the walls. By comparing these values, the program determines whether the ball should bounce, continue moving, or trigger a game over.

- For the paddle collision, the code checks whether the ball’s horizontal position overlaps with the paddle and whether the ball reaches the same vertical level. If both conditions are met, the ball changes direction.

- The game runs inside a continuous update loop, which repeatedly updates object positions and checks the game state to create smooth animation.
