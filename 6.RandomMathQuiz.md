# Math Quiz with Turtle (Python)

## 1. Programming Language(s) Used
- Python 3
- Turtle graphics module
- Random module

## 2. Purpose of the Code (Main Functionality)
This project creates a simple math quiz using Python's Turtle graphics module.

The program randomly generates two numbers between 1 and 100 and randomly selects either addition or multiplication. It then displays the math question in a pop-up input box. The user enters their answer, and the program checks whether it is correct.

If the answer is correct, a success message is written on the screen. Otherwise, an error message is displayed. The correct answer is also printed in the console for reference.

The purpose of this project is to practice random number generation, conditional logic, user calculation ability.

## 3. Scale of the Project
- Single script program
- Uses random number generation
- Uses conditional branching (if / else)
- Displays graphical output using Turtle
- Accepts user input through a pop-up dialog

## 4. Use of Object-Oriented Concepts
This project mainly focuses on procedural logic rather than full object-oriented design. However, it makes use of built-in Turtle objects to display graphical output on the screen.

The program demonstrates structured flow control by separating the logic for addition and multiplication using conditional statements.

## 5. Use of Data Structures
The program uses:
- A list (`['+', '×']`) to randomly select the type of operation
- Integer variables to store generated numbers and user input

These simple data structures are used to control program behavior and evaluate correctness.

## 6. Interesting Use of Data Structures / Algorithms
The main logic involves:
- Randomly selecting numbers and operators
- Constructing a formatted math question
- Comparing user input with the calculated correct result
